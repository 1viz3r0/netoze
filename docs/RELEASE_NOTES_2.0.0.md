# netoze 2.0.0 Release Notes

## Included

- netoze desktop investigation workspace.
- Overview and globe-based evidence view.
- Capture Buddy with native capture and packet analysis paths.
- Watchtower, Scan Buddy, local evidence, and native forensic query workflows.
- 100% in-house proprietary analysis engine with zero external dependencies.
- Linux DEB/AppImage and Windows x64 NSIS distribution artifacts.

## Security and Integrity

- Verify platform-specific SHA-256 signatures before installation.
- Linux live capture is limited to native capture-helper architecture; portable AppImage runs without elevated privileges.
- Windows live capture requires native Windows host acceptance.
- The public release repository contains no private source code or backend data.
- Treat artifacts as self-published until official code-signing certificates are attached.
