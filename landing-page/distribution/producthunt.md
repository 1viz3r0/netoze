## Description
netoze is an elite digital infrastructure and local-first network monitoring platform built for engineers and security analysts. 

Traditional tools force a compromise between disconnected packet dumps and invasive cloud SIEM agents. netoze provides a unified, 100% self-made local-first workflow:
1. **Orient**: Real-time interface and socket state mapping.
2. **Trace**: Direct correlation of network wire frames to host processes and PIDs.
3. **Explain**: Verifiable local evidence stores and forensic briefs.

All processing runs 100% offline on your workstation with zero external telemetry egress.
