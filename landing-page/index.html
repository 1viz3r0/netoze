Frequently Asked Questions

Everything you need to know about NET0ZE (Neetoze).

Clear, direct answers regarding the NET0ZE platform architecture, packet forensics, operating system compatibility, and privacy guarantees.

What is NET0ZE (also known as Neetoze)? +

NET0ZE (commonly searched phonetically as Neetoze) is an open, local-first cybersecurity investigation and network monitoring desktop platform. It enables SOC analysts, network engineers, penetration testers, and security researchers to inspect live packet captures, analyze host process telemetry, and correlate network flows into clear forensic briefs without transmitting private network data to external cloud servers.

How does NET0ZE compare to Wireshark for network packet analysis? +

Wireshark is the standard for raw packet dissection, but it presents a high cognitive load and lacks native integration with host processes or high-level relationship mapping. NET0ZE connects the wire to the machine: it groups packets into flows, maps them to local socket states and process identifiers, and guides the investigator through a streamlined Orient → Trace → Explain loop.

Does NET0ZE send network traffic or telemetry to external servers? +

No. NET0ZE operates strictly under a 100% local-first and zero-telemetry philosophy. Your packet captures, network metrics, IP addresses, and incident notes remain on your physical hardware. No analytical beacons, tracking scripts, or cloud egress channels are bundled in the application.

Which operating systems are supported by NET0ZE? +

NET0ZE supports 64-bit Windows 10 and Windows 11 (via NSIS installer requiring approved Npcap driver) and Linux distributions such as Ubuntu, Debian, Fedora, and Arch Linux (available via Debian .deb package and portable .AppImage). macOS and Android packages are actively planned on the technical roadmap.

How do Docker-backed Cybersecurity Labs work in NET0ZE? +

NET0ZE includes integrated local Docker challenges that run on loopback interfaces. Analysts can deploy realistic network exposure scenarios, analyze live HTTP/DNS/TCP behavior, trace vulnerabilities, and submit findings in an isolated, resettable local sandbox without external risk.

How can I download and install NET0ZE (Neetoze)? +

Official release artifacts are available directly from the Downloads section on this website (neetoze.surge.sh) and mirrored on the official GitHub repository at github.com/1viz3r0/netoze. Every package is accompanied by cryptographic SHA256 checksums.
