Install

Deployment Guide

Verification steps for production execution.

Windows

  1. Download NET0ZE_2.0.0_x64-setup.exe from official releases.
  2. Verify SHA-256 sum via PowerShell: Get-FileHash .\NET0ZE_2.0.0_x64-setup.exe -Algorithm SHA256
  3. Run installer to deploy to workstation user directory.

Linux

  1. Download the .deb or portable .AppImage from official releases.
  2. Verify hash integrity: sha256sum ./NET0ZE_2.0.0_amd64.deb
  3. Install package: sudo apt install ./NET0ZE_2.0.0_amd64.deb
  4. Launch netoze from terminal or applications menu.
